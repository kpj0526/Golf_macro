# Golf_macro

Sun Valley golf reservation macro recovery source.

The repository contains the C# application source, safe test sources, and selected
recovery documentation. Build output, local diagnostics, browser binaries, and all
account-bearing runtime configuration are intentionally excluded.

  ```powershell
  py tools/install_golf_catch.py
  ```
